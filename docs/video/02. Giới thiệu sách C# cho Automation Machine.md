## Nguồn tham khảo đã xác minh (để trích dẫn đúng, không suy đoán)

- Trang chủ tài liệu: `https://controlbee.hotbee.ai/`
- README dự án chính (GitHub `hot-bee/ControlBee`): tagline chính thức —
  *"The world's first open-source platform for machine control in manufacturing fields
  such as semiconductors, secondary batteries, and solar power."*
- Giấy phép: MIT License
- Tác giả: Leo Younghyo Kim (công ty Hotbee, Hàn Quốc)
- Lấy cảm hứng từ: Akka (framework Actor Model nổi tiếng bên JVM/Scala) — dự án tự ghi
  trong README phần Acknowledgments
- Kiến trúc: tách thành 5 repo độc lập, publish riêng qua NuGet/GitHub Packages —
  `ControlBeeAbstract` (interfaces), `ControlBee` (core), `ControlBeeWPF` (UI), `ControlBeeTest`
  (test helper), `ControlBeeExamples` (ví dụ Pick-and-Place thực tế)
- Ý tưởng kiến trúc cốt lõi: **Actor Model** — mỗi Actor là 1 đơn vị tính toán độc lập
  (thread + mailbox + state machine riêng), giao tiếp qua message, không truy cập trực tiếp
  state của nhau — khác với mô hình MasterController → Station → Mechanism truyền thống mà
  sách trình bày
- 4 lý do dự án đưa ra cho việc dùng Actor trong automation: decomposition tự nhiên theo
  từng cụm cơ khí thật, chạy song song không chặn nhau, cô lập lỗi (1 actor lỗi không sập
  toàn hệ thống), điều phối rõ ràng qua message (dễ trace/debug)
